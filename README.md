# Weather-dash-app

A simple weather dashboard web application built with JavaScript, Dash, and OpenWeather API that lets users check current weather and forecast based on city input.

Features:

🔍 Search weather by city name

🌡️ Shows current temperature & conditions

🌍 Simple and interactive dashboard UI


This app needs an API key from OpenWeather:

1.Create free account at: https://openweathermap.org

2.Get API key

3.Save it as environment variable: [setx OPENWEATHER_API_KEY "your_api_key_here"]
